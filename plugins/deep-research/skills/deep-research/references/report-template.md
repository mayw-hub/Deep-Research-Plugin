# Title

## Summary
Three to six lines: the answer, the strength of evidence, the main caveat.

## Evidence table
One row per included source: citation [n] | design | population and n | timing and parameters | outcomes | key numbers | direct or indirect | full text or abstract only. Leave a cell as "not reported" rather than guessing.

## <sub-question>
Repeat one section per sub-question. Separate direct from indirect evidence. Use citations as `[n]`.

## What to say on stage
Only when the user asked for a talk or practice recommendations. Short actionable statements, each with its evidence level (guideline / RCT / meta-analysis / observational / expert opinion), caveats and the citations.

## Figures worth showing
Only when the user asked for presentation material. Ranked list: figure or table number, source [n], why it is worth showing. Only list figures whose numbers appear in the fetched text; otherwise write "figure number not verified".

## Timeline
Only when the topic is a procedure with phases. A mermaid `timeline` or `flowchart` block.
