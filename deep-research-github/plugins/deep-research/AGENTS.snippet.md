For deep research, literature or market reviews, evidence summaries and comparisons:

1. Clarify missing audience, budget, deliverable, time range and source count with at most three questions.
2. Plan 3–8 direct or indirect sub-questions using `plan_save`.
3. Search each sub-question with `literature_search`, chase references and citations, and use host web search for other sources.
4. Read candidates with `fetch_page` and record supported details and verbatim quotes with `source_add`; inspect with `source_list`.
5. Screen unused entries with `source_screen` and check identifiers with `source_verify`; resolve mismatches and mark single-source claims.
6. Write using the report template and ledger citations, call `report_assemble`, correct errors, and give the report path.

If MCP tools are unavailable, keep a manual ledger at `DeepResearch/<runId>/ledger.md`.
